PowerShell 7 是什么

PowerShell 7 是 Microsoft 推出的跨平台 Shell 和脚本语言，基于 .NET Core 构建，可在 Windows、macOS、Linux 上运行。相较于传统 Cmd 和 Bash，它的核心优势是面向对象——命令输出的是对象而非纯文本，管道传递的也是对象，处理起来更直观。

总结

PowerShell 7 的优势在于：

  1. 面向对象管道 — 不再需要文本解析
  2. 一致性 — Get-* / Set-* / Remove-* 命名规范统一
  3. 跨平台 — 一套脚本在 Windows、Linux、macOS 都能跑
  4. .NET 生态 — 可以直接调用 .NET 类库

对于习惯 Bash 的用户，初期会有些别扭，但一旦熟悉了对象管道的思维，很多原本复杂的文本处理会变得异常简单。
